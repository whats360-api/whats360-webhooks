# Contributing

Thanks for helping improve this project.

- Only document or implement behavior that Whats360 officially documents or that you verified against your own account. Say which in the pull request.
- Never include real tokens, phone numbers, device IDs, webhook URLs or secrets. Use placeholders like YOUR_TOKEN and DEVICE_ID.
- Keep changes small and focused. Update the CHANGELOG.
- Open an issue before large changes.

Questions about the platform: info@whats360.live or https://wa.me/whats360.live
