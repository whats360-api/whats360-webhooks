# Whats360 Webhooks (WhatsApp Webhook Guide)

How to send WhatsApp events from [Whats360](https://whats360.live) to your systems, and how to turn events from other systems (Shopify, WooCommerce, n8n, custom) into WhatsApp messages.

- [Webhook guide](webhooks-guide.md)
- API reference: [whats360-api-docs](https://github.com/whats360-api/whats360-api-docs)

Your receive URL and secret are private to your account. Do not publish them.
