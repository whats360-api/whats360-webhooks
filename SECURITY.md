# Security Policy

## Never publish credentials
whats360.live API tokens, device (instance) IDs tied to your account, webhook receive URLs and webhook secrets are private to your account. Do not commit them to this or any public repository, issue, or pull request. Use environment variables.

## Reporting a vulnerability or an exposed secret
Email info@whats360.live. Do not open a public issue with sensitive details. If you exposed a token, regenerate it in the whats360.live dashboard first.

Official site: https://whats360.live
